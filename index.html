Seguridad del laboratorioDocker publica el puerto solo en 127.0.0.1. Este servicio es deliberadamente vulnerable y no se debe publicar en Internet.

Los archivos internos, el servicio SSRF y las compras son simulaciones locales. No se realizan cobros, peticiones a Internet ni lecturas de archivos del anfitrión.

Guía del entorno autorizado Ejecuta docker compose up --build -d y abre http://127.0.0.1:8000. Para los retos HTTP utiliza Burp Suite → Proxy → HTTP history → Repeater. Las simulaciones se resuelven con evidencias ficticias y una decisión de remediación; las herramientas nombradas son referencias para el aprendizaje, no se ejecutan desde la web.
